# Demonstration photo sources and usage

The website displays external reference photography via `images.unsplash.com` URLs in the user's browser. No images are downloaded or embedded in the ZIP; the SVG illustrations in `static/illustrations/` are original fallback assets. Demo photographs are **not actual photos of the specific merchandise**, and are used only to demonstrate a product storefront.
